# Global Agent Rules

## Pi Configuration

My pi configuration directory is at `~/.config/pi/` instead of the default `~/.pi/`. All pi agent files (settings, extensions, skills, themes, sessions, etc.) live under this path.

## File Formatting

Always ensure every file ends with exactly one trailing newline (`\n`). When writing or editing files, add a newline at the end if one is missing. Do not create files without a trailing newline.
